my_keyboard — corrected QMK/Vial files

Hardware:
- RP2040
- 6 rows x 4 columns
- ROW2COL diodes
- 21 matrix keys
- Encoder 0: GP14 / GP15, resolution 4
- Encoder 1: GP16 / GP22, resolution 4
- Encoder push buttons: matrix [0,0] and [0,3]
- 3 Vial layers

Use info.json as the QMK keyboard definition. keyboard.json is also included as a modern-QMK equivalent.
